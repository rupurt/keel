# Extract Shared Txt Scene Engine

> Rich terminal surfaces in Keel are still hand-rendered with command-specific spacing, connector math, and ANSI-aware padding logic. That drift has already produced repeated rendering bugs. We need one reusable `txt-scene` crate that owns semantic scene state, retained-tree layout, fixed-width 2D rendering, post-layout styling, connector routing, Unicode width policy, debug overlays, and a migration path starting with `flow`.
