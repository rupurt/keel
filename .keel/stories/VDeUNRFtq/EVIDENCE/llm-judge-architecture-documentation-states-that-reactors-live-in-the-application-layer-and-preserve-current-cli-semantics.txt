... 280 ## Application Reactor Pipeline
... 281 
... 282 Cross-aggregate lifecycle automation lives in the application layer, not in CLI
... 283 adapters or domain entities. The canonical path is:
... 284 
... 285 1. A lifecycle service or command adapter completes an existing transition and emits a `DomainEvent`.
... 286 2. `src/application/process_manager.rs` dispatches that event through explicit application-layer reactors.
... 287 3. Reactors plan follow-up `ProcessAction`s that reuse the existing lifecycle services.
... 288 
... 289 This preserves current CLI semantics: commands remain thin adapters that
... 290 delegate into application services, while reactor rules stay in
... 291 `src/application/**` and do not move into `src/cli/**` or `src/domain/**`.
... 292
